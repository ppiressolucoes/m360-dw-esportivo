# HTML [1] Publicar Jogos Fases Competição

Pasta oficial de manutenção do fluxo n8n **HTML [1] Publicar Jogos Fases Competição**.

## Fonte de verdade

A partir desta pasta, os códigos versionados no repositório passam a ser a fonte de verdade para manutenção do fluxo.

## Histórico inicial

- `node-8.2/M360_Node_8.2_v5_Pontos_Corridos_Estadio.txt` — versão atualizada do Node 8.2, com correção da duplicação do nome do estádio nos cards da agenda de competições de pontos corridos.

## Regra de manutenção

- Sempre versionar o código completo em TXT UTF-8.
- Não utilizar ZIP como fonte de edição.
- Alterações futuras devem partir da última versão oficial armazenada neste diretório.
- Preservar a lógica homologada de outras competições, especialmente Libertadores 2026.
